01개요 & 목적

테이블 에디터는 게임 데이터 테이블 작업(원본 편집 → 바이너리 변환 → 코드 생성)의 전 과정을 하나의 GUI 창에서 처리하는 Windows 독립 실행 파일이다. TableAutomationTool 솔루션에 프로젝트로 추가되며, CLI(tabletool)와 동일한 엔진(DLL)을 직접 참조해 동작한다.

항목내용
대상 사용자기획자 · 데이터 담당자 · 클라이언트 개발자 (테이블을 편집하고 바이너리/코드를 뽑는 사람)
실행 환경Windows 데스크톱 앱(.NET WPF, TableEditor.exe). CLI와 같은 Output 폴더에 배치되어 Config를 공유
핵심 가치① 창 하나에서 끝냄 ② 팝업 없는 탭 전환 ③ 전체/개별 처리 일관 지원

지원 기능(이번 범위)

기능설명상태
편집 (뷰어 통합)테이블 조회·검색 + 셀 값 편집 + 신규 테이블 추가. 원본은 GSheet · xlsx 둘 다 지원이번
데이터 추출원본 → .bin 변환. 전체 & 개별 지원이번
코드 추출.bin → C#/C++ 클래스 생성. 전체 & 개별 지원이번
설정각 엔진(Enum/ExcelToData/CodeGen/GAuth)의 경로·옵션 설정 관리이번

02설계 원칙

① 팝업 → 탭 전환

별도 창·모달 팝업을 없애고, 센터 상단 기능 탭으로 화면을 갈아끼운다. 맥락이 끊기지 않고 이동이 한 번의 클릭으로 끝난다.

② 단일 진입점

TableEditor.exe 하나로 모든 기능 진입. 창을 여러 개 띄우지 않는다.

③ 전체/개별 일관

데이터·코드 추출 모두 전체 실행과 선택 항목만을 같은 UI 패턴(체크박스 목록 + [전체]/[선택] 버튼)으로 제공. 내부적으로 개별은 엔진의 -each로 매핑.

④ 상태·로그 상시 노출

실행 진행/성공/실패는 팝업 대신 창 하단 상태 바 + 로그 패널에 남긴다. 실패는 색·아이콘으로 구분.

03정보 구조(IA) & 네비게이션

테이블 에디터 (단일 창 · 센터 상단 기능 탭)
├─ 편집          뷰어 포함: 조회 · 검색 · 셀 수정 · 신규 테이블 (GSheet / xlsx)
├─ 데이터 추출    원본 → .bin  (전체 / 개별)
├─ 코드 추출      .bin → C#/C++ (전체 / 개별)
└─ 설정          엔진별 경로 · 옵션 세팅

네비게이션 모델: 센터 상단 가로 기능 탭 4개. 클릭 시 아래 콘텐츠 영역이 해당 기능 화면으로 전환된다. 각 탭의 상태(선택·검색어·체크·스크롤)는 세션 동안 유지되어 탭을 오가도 잃지 않는다.

페이지 전환 규칙 기존에 팝업·별도 창으로 열리던 기능(컬럼 필터, Config 창 등)은 전부 탭 내 화면/사이드 패널로 흡수한다. 모달 다이얼로그는 파괴적 확인(삭제·덮어쓰기·미저장 이탈)에만 예외적으로 사용.

05탭 — 편집 (뷰어 통합)

목적: 테이블을 찾아 열고(뷰어), 셀 값을 수정하고, 신규 테이블을 추가한다. 원본은 xlsx와 GSheet 둘 다 지원한다. 조회와 편집은 별도 페이지가 아니라 이 탭 하나에서 이루어진다.

┌ 편집 ───────────────────────────────────────────────────────────────┐
│ 원본 (◉ xlsx  ○ GSheet)   시트 [ Sheet1 ▾ ]     [+ 신규 테이블] [저장] │
├───────────────┬─────────────────────────────────────────────────────┤
│ [검색어… ][검색]│  Id   │ Name          │ Price    │ Type            │  ← 좌측 상단: 검색
├───────────────┤ ──────┼───────────────┼──────────┼───────────────── │
│ ▸ Item        │  1001 │ Iron Sword    │[ 120  ]  │ Weapon           │
│   Character   │  1002 │ Health Potion │ 30       │ Consumable       │
│   Skill       │   …   │               │          │                  │
│   Stage       │                                                     │
│               │                                                     │
│  (테이블 리스트)│                                                     │
├───────────────┴─────────────────────────────────────────────────────┤
│ 변경 3건 · 미저장                        [되돌리기]  [저장 후 데이터 추출] │

좌측 — 테이블 리스트 & 검색

요소동작
검색 입력 + [검색] 버튼좌측 상단 고정. 검색 버튼을 눌렀을 때 검색어를 포함하는 테이블만 리스트에 표시(대소문자 무시). 검색어가 비어 있으면 전체 테이블 표시. Enter로도 실행
테이블 리스트원본 소스(xlsx 폴더 / GSheet 폴더)의 테이블 목록. 클릭 시 우측 그리드에 로드. 선택 항목 강조

우측 — 데이터 그리드 (뷰어 + 편집)

요소동작
원본 선택 (xlsx / GSheet)소스 전환 시 테이블 리스트 갱신. xlsx는 Config의 원본 폴더, GSheet는 GAuth 인증 + 폴더 링크 사용
시트 선택xlsx 파일에 시트가 여럿일 때 전환
셀 편집더블클릭 → 인라인 편집. 헤더 규약(1행 컬럼명·2행 타입)은 그리드에서 보호되고 데이터 행만 편집
신규 테이블 추가[+ 신규 테이블] → 탭 내 인라인 패널(팝업 아님)에서 테이블명·컬럼(이름:타입) 정의 후 생성. 헤더 2행 규약 자동 세팅. 산출물은 원본 폴더의 xlsx 파일
저장변경분을 원본에 반영. 미저장 변경 건수 하단 표시. GSheet는 1차에서 읽기 전용(§12 D2)
저장 후 데이터 추출저장과 동시에 해당 테이블만 -each 바이너리 추출로 연결(선택 기능)

상태·예외: 로드 실패 시 상태 바에 오류 + 빈 그리드. 미저장 상태에서 다른 테이블/탭 이동 시 확인.

06탭 — 데이터 추출

목적: 원본(xlsx/GSheet) → .bin 변환. 전체 또는 선택 항목만.

┌ 데이터 추출 ─────────────────────────────────────────────────────────┐
│  소스: ◉ 로컬 xlsx   ○ GSheet 폴더            [목록 새로고침]         │
│  [☑ 모두]                                                            │
│  ┌ 테이블 목록 ───────────────┐   ┌──────────────────────┐          │
│  │ ☑ Item                     │   │  [ 전체 추출 ]         │          │
│  │ ☑ Character                │   ├──────────────────────┤          │
│  │ ☐ Skill                    │   │  [ 선택 추출 ]         │          │
│  │ ☑ Stage                    │   └──────────────────────┘          │
│  └────────────────────────────┘                                     │
│  진행 ▓▓▓▓▓▓▓░░░  Item → Item.bin …                                  │
└─────────────────────────────────────────────────────────────────────┘
요소동작 / 매핑
소스 선택로컬 xlsx 또는 GSheet 폴더. GSheet 개별 추출은 엔진의 -each 클라이언트 필터 활용
전체 추출목록 전부 → ExcelToData 엔진 전체 실행
선택 추출체크 항목만 → 각 항목 -each <이름> 실행
완료 후결과를 상태 바·로그에 남김. 산출 .bin은 코드 추출 탭 목록에 반영
알아둘 점 — GSheet 개별 추출 GSheet는 폴더 전체 탭을 내려받은 뒤 이름으로 필터하므로, 개별 선택이어도 네트워크 다운로드는 전체이고 저장되는 .bin만 선택분으로 줄어든다.

07탭 — 코드 추출

목적: .bin → C#/C++ 클래스 생성. 전체 또는 선택 항목만. (데이터 추출 탭과 동일 패턴)

│  출력 언어: C# (설정 탭에서 변경)     ☑ Enum 코드 함께 생성           │
│  [☑ 모두]                                                            │
│  ┌ 바이너리 목록 (.bin) ──────┐   ┌──────────────────────┐          │
│  │ ☑ Item                     │   │  [ 전체 생성 ]         │          │
│  │ ☐ Character                │   ├──────────────────────┤          │
│  │ ☑ Stage                    │   │  [ 선택 생성 ]         │          │
│  └────────────────────────────┘   └──────────────────────┘          │
│  결과: Item.cs, Stage.cs 생성 (2)                                    │
└─────────────────────────────────────────────────────────────────────┘
요소동작 / 매핑
출력 언어설정 탭의 확장자 규약(C#/C++)을 표시. 변경은 설정 탭에서
Enum 코드 함께체크 시 Enum 생성(EnumDB) 선행 실행(전체 단위)

08탭 — 설정

목적: 각 엔진이 쓰는 Config를 GUI로 편집·생성한다. (구 별도 Config 창을 탭으로 흡수)

┌ 설정 ───────────────────────────────────────────────────────────────┐
│  ▾ 데이터 추출 (ExcelToData)                                          │
│      ☑ 로컬 사용   Src [ …/Data     ] [찾기]   Dst [ …/Binary ] [찾기] │
│      ☐ GSheet 사용  GDrive 링크 [ …                              ]    │
│  ▾ JSON 추출        Src [ … ]  Dst [ … ]                             │
│  ▾ 코드 생성 (CodeGenerator)                                          │
│      Binary [ … ]  Class 출력 [ … ]  네임스페이스 [ … ]  확장자 [.cs ▾] │
│      ☑ Enum 코드 생성   Enum 출력 [ … ]                               │
│  ▾ Enum 생성        Enum 파일 [ … ]  시트 패턴 [ *Enum*,*enum* ]      │
│  ▾ GAuth            client_secret [ … ]  User [ … ]                  │
│                                                                     │
│  [기본값 생성]                                  [검증]  [저장]        │
└─────────────────────────────────────────────────────────────────────┘
요소동작
엔진별 섹션ExcelToData(Binary/JSON) · CodeGenerator · EnumGenerator · GAuth 각각의 실제 Config 필드를 편집(접이식)
기본값 생성각 Config를 엔진 기본값으로 리셋(저장 전까지 파일 미변경)
검증필수 경로 존재/형식 확인. 문제 항목 인라인 경고
저장각 엔진 Config(JSON) 파일에 기록. 없으면 생성(init-config 동등)

이 탭의 값은 편집·추출 탭이 공유하는 단일 진실이다. Config 파일 위치·형식은 CLI와 동일(Config/*.json)해서 CLI와 혼용 가능.

09공통 UX 패턴

패턴규칙
선택 목록체크박스 목록 + [모두] 토글 + [전체]/[선택] 실행 버튼. 데이터·코드 추출 탭 동일
진행 표시실행 중 진행 표시 + 현재 항목명. 실행 중 관련 버튼 비활성
결과/로그하단 상태 바 요약 + 펼침 로그 패널. 성공 녹색 / 실패 적색
모달 최소화정보 전달은 탭/패널로. 모달은 삭제·덮어쓰기·미저장 이탈 확인에만
미저장 보호편집 탭 이탈/창 닫기 시 미저장 변경 있으면 확인
단축키Ctrl+S 저장 · Enter 검색 실행 · F5 목록 새로고침

  xlsx ─┐

  GSheet┘         ▲                            ▲

                  ▲
             EnumDB.bin  ◀── (Enum 생성, 전체 단위)

  편집 탭  ── 원본(xlsx/GSheet)을 읽어 표시 · 수정 · 신규 테이블 생성

편집→저장→추출→코드생성이 한 창 안에서 연결되며, 모든 경로·옵션의 출처는 설정 탭 한 곳이다. 엔진은 CLI와 동일 DLL을 직접 참조하므로 동작·산출물이 CLI와 완전히 일치한다.

11범위 밖 & 향후

  • 향후 Table Loader — UI/UX 미정으로 이번 제외. 확정되면 설정 탭 이관 여부 재검토.
  • 향후 런타임 뷰어 — 데이터를 실제 게임에서 보여주는 부분은 엔진별 개별 구현(Unity/Unreal 등). 본 툴 범위 밖.
  • 향후 GSheet 원본 직접 쓰기 · 다중 정렬 · 컬럼 필터 패널 · 변경 이력/undo 스택 · 대량 편집(찾아 바꾸기).

12결정 사항 & 미확정

D1. 확정 — 뷰어와 편집 통합 별도 페이지가 아니라 편집 탭 하나에서 조회+편집. (v0.1 Q1 해소)
D2. 확정 — GSheet는 1차 읽기 전용 GSheet 원본은 조회·추출 지원. 셀 편집 저장(원본 되쓰기)은 쓰기 권한·API 반영이 필요해 후속 단계로 미룬다. (v0.1 Q2 부분 확정)
D3. 확정 — 엔진 호출은 DLL 직접 참조 같은 솔루션 내 프로젝트 참조로 Invoker를 직접 호출. exe 프로세스 호출 없음. (v0.1 Q3 해소)
D4. 확정 — 신규 테이블 산출물은 xlsx 신규 테이블 추가는 원본 폴더에 헤더 2행 규약의 xlsx 파일 생성. GSheet 신규 시트는 향후. (v0.1 Q4 해소)
D5. 확정 — UI 기술은 WPF 독립 실행 파일 요구에 따라 Unity가 아닌 .NET WPF. (v0.1 Q5 해소)
미확정 — 저장 후 데이터 추출 기본값 편집 탭의 [저장 후 데이터 추출]을 기본 켬으로 할지. 1차 구현은 별도 버튼(수동)으로 제공.
