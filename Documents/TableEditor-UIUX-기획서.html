01개요 & 목적

테이블 에디터는 게임 데이터 테이블 작업(원본 편집 → 바이너리 변환 → 코드 생성)의 전 과정을 하나의 GUI 창에서 처리하기 위한 Unity Editor 도구다. 기존에 CLI(tabletool)와 흩어진 에디터 윈도우/팝업으로 나뉘어 있던 기능을 단일 툴 + 페이지 전환 구조로 통합한다.

항목내용
대상 사용자기획자 · 데이터 담당자 · 클라이언트 개발자 (테이블을 편집하고 바이너리/코드를 뽑는 사람)
실행 환경Unity Editor 내 도킹 가능한 에디터 툴 (EditorWindow). 내부적으로 TableAutomationTool 엔진을 호출
핵심 가치① 창 하나에서 끝냄 ② 팝업 없는 페이지 이동 ③ 전체/개별 처리 일관 지원

지원 기능(이번 범위)

기능설명상태
뷰어테이블 데이터 조회 · 검색 · 컬럼 필터 · 정렬이번
값 수정 & 신규 테이블셀 값 편집 및 신규 테이블 추가. 원본은 GSheet · xlsx 둘 다 지원이번
Config 세팅각 엔진(Enum/ExcelToData/CodeGen)의 경로·옵션 설정 관리이번
바이너리 추출원본 → .bin 변환. 전체 & 개별 지원이번
코드 추출.bin → C#/C++ 클래스 생성. 전체 & 개별 지원이번

02설계 원칙

① 팝업 → 페이지 전환

별도 창·모달 팝업(예: 컬럼 필터 팝업, 별도 Config 윈도우)을 없애고, 좌측 네비게이션으로 페이지를 갈아끼우는 방식으로 통일한다. 맥락이 끊기지 않고 뒤로가기가 자연스럽다.

② 단일 진입점

메뉴 Tools ▸ Table Editor 하나로 모든 기능 진입. 창을 여러 개 띄우지 않는다.

③ 전체/개별 일관

바이너리·코드 추출 모두 전체 실행과 선택 항목만을 같은 UI 패턴(체크박스 목록 + [전체]/[선택] 버튼)으로 제공. 내부적으로 개별은 엔진의 -each로 매핑.

④ 상태·로그 상시 노출

실행 진행/성공/실패는 팝업 대신 창 하단 상태 바 + 로그 패널에 남긴다. 실패는 색·아이콘으로 구분.

03정보 구조(IA) & 네비게이션

테이블 에디터 (단일 창)
├─ 뷰어            데이터 보기 · 검색 · 필터
├─ 편집            셀 수정 · 신규 테이블 추가 (GSheet / xlsx)
├─ Config          엔진별 경로 · 옵션 세팅
├─ 바이너리 추출    원본 → .bin  (전체 / 개별)
└─ 코드 추출        .bin → C#/C++ (전체 / 개별)

네비게이션 모델: 좌측 세로 탭(페이지 목록). 클릭 시 우측 콘텐츠 영역이 해당 페이지로 전환된다. 페이지 상태(선택·필터·스크롤)는 세션 동안 유지되어 페이지를 오가도 잃지 않는다.

페이지 전환 규칙 이전에 팝업으로 뜨던 컬럼 필터는 뷰어 페이지 내 우측 사이드 패널(슬라이드 인)로, 별도 창이던 Config는 Config 페이지로 흡수한다. 모달 다이얼로그는 파괴적 확인(삭제·덮어쓰기)에만 예외적으로 사용.

05페이지 — 뷰어

목적: 선택한 테이블의 데이터를 표로 확인하고 검색·필터·정렬한다. (읽기 전용, 편집은 편집 페이지에서)

┌ 뷰어 ───────────────────────────────────────────────────────────────┐
│ 테이블 [ Item ▾ ]   🔍 [ 검색어…            ]   [필터 ▸]   행 1,240 │
├──────┬───────────────┬──────────┬───────────────┬────────────────────┤
│ Id   │ Name          │ Price ▲  │ Type          │ …                  │
├──────┼───────────────┼──────────┼───────────────┼────────────────────┤
│ 1001 │ Iron Sword    │ 120      │ Weapon        │ …                  │
│ 1002 │ Health Potion │ 30       │ Consumable    │ …                  │
│  …   │               │          │               │  ┌─ 필터 패널 ───┐ │
│      │               │          │               │  │ Type          │ │
│      │               │          │               │  │ ☑ Weapon      │ │
│      │               │          │               │  │ ☐ Consumable  │ │
│      │               │          │               │  │ [적용][해제]   │ │
└──────┴───────────────┴──────────┴───────────────┴──└───────────────┘─┘
요소동작
테이블 선택드롭다운으로 로드된 테이블 전환. 소스(.bin 또는 원본)에서 로드
검색전 컬럼 텍스트 검색(대소문자 무시). 결과 행 수 표시
컬럼 필터우측 슬라이드 패널(구 ColumnFilterPopup 대체). 컬럼별 값 체크로 필터
정렬헤더 클릭 시 오름/내림. 다중 정렬은 향후
컬럼 표시/숨김넓은 테이블 대응. 표시 컬럼 토글

상태·예외: 로드 실패 시 상태 바에 오류 + 빈 표. 대용량은 가상 스크롤(행 지연 렌더)로 대응.

06페이지 — 편집 / 신규 테이블

목적: 셀 값을 수정하고 신규 테이블을 추가한다. 원본은 GSheet와 xlsx 둘 다 지원한다.

┌ 편집 ───────────────────────────────────────────────────────────────┐
│ 원본 (○ xlsx  ○ GSheet)     테이블 [ Item ▾ ]   [+ 신규 테이블]      │
├──────┬───────────────┬──────────┬───────────────────────────────────┤
│ Id   │ Name          │ Price    │  … (셀 더블클릭 → 인라인 편집)      │
├──────┼───────────────┼──────────┼───────────────────────────────────┤
│ 1001 │ Iron Sword    │[ 120  ]  │  ← 편집 중                          │
│ 1002 │ Health Potion │ 30       │                                   │
├──────┴───────────────┴──────────┴───────────────────────────────────┤
│ 변경 3건 · 미저장            [되돌리기]  [저장]  [저장 후 바이너리 추출] │
└─────────────────────────────────────────────────────────────────────┘
요소동작
원본 선택 (xlsx / GSheet)편집 대상 소스 전환. GSheet는 GAuth 인증 + 폴더/시트 지정, xlsx는 로컬 파일
셀 편집더블클릭 → 인라인 편집. 타입 검증(숫자/enum/bool 등)
신규 테이블 추가테이블명 · 컬럼(이름/타입) 정의 후 생성. 헤더 규약(타입행 등) 자동 세팅
저장변경분을 원본(xlsx 파일 / GSheet)에 반영. 미저장 변경 건수 표시
저장 후 추출저장과 동시에 해당 테이블만 -each 바이너리 추출로 연결(선택)
주의 — GSheet 쓰기 GSheet 편집을 원본에 되쓰려면 Sheets 쓰기 권한과 API 반영이 필요하다. 현재 파이프라인은 GSheet를 읽기 위주로 사용하므로, 쓰기 지원 범위(직접 되쓰기 vs 로컬 캐시 후 수동 반영)는 §13에서 확정 필요.

07페이지 — Config 세팅

목적: 각 엔진이 쓰는 Config를 GUI로 편집·생성한다. (구 GameDataToolConfigSetting 별도 창을 페이지로 흡수)

┌ Config ─────────────────────────────────────────────────────────────┐
│  공통 경로                                                            │
│    Table(원본) 폴더  [ …/Data            ] [찾기]                     │
│    Binary 폴더       [ …/Output          ] [찾기]                     │
│    Code 출력 폴더    [ …/Scripts/DataScript ] [찾기]                  │
│  ────────────────────────────────────────────────────────────────    │
│  ▾ EnumGenerator     Src [ … ]  Dst [ … ]                            │
│  ▾ ExcelToData       Src [ … ]  Dst [ … ]   ☑ Local  ☐ GSheet       │
│  ▾ CodeGenerator     Src [ … ]  Dst [ … ]   출력: ◉ C#  ○ C++        │
│  ▾ GAuth             client_secret [ … ]  User [ … ]                 │
│                                                                     │
│  [기본값 생성(init-config)]                    [검증]  [저장]         │
└─────────────────────────────────────────────────────────────────────┘
요소동작
공통 경로Table/Binary/Code 폴더 지정 → 각 엔진 Config에 반영
엔진별 섹션Enum/ExcelToData/CodeGen/GAuth 각각 Src·Dst·옵션 편집(접이식)
기본값 생성Config 없을 때 각 엔진 init-config로 템플릿 생성 후 값 주입
검증필수 경로 존재/형식 확인. 문제 항목 인라인 경고
저장각 엔진 Config(JSON) 파일에 기록

이 페이지의 값은 뷰어·편집·추출 페이지가 공유하는 단일 진실이다. 최종적으로는 Table Loader로 이동 예정(§12).

08페이지 — 바이너리 추출

목적: 원본(xlsx/GSheet) → .bin 변환. 전체 또는 선택 항목만.

┌ 바이너리 추출 ───────────────────────────────────────────────────────┐
│  소스: ◉ 로컬 xlsx   ○ GSheet 폴더            [목록 새로고침]         │
│  [☑ 모두]                                                            │
│  ┌ 테이블 목록 ───────────────┐   ┌──────────────────────┐          │
│  │ ☑ Item                     │   │  [ 전체 추출 ]         │          │
│  │ ☑ Character                │   ├──────────────────────┤          │
│  │ ☐ Skill                    │   │  [ 선택 추출 ]         │          │
│  │ ☑ Stage                    │   └──────────────────────┘          │
│  └────────────────────────────┘                                     │
│  진행 ▓▓▓▓▓▓▓░░░  Item → Item.bin …                                  │
└─────────────────────────────────────────────────────────────────────┘
요소동작 / 매핑
소스 선택로컬 xlsx 또는 GSheet 폴더. GSheet 개별 추출은 이번에 추가된 -each 필터 활용
전체 추출목록 전부 → tabletool extract (옵션 없음)
선택 추출체크 항목만 → 각 extract -each <이름>
완료 후결과를 로그에 남기고, Unity면 AssetDatabase.Refresh() 호출
알아둘 점 — GSheet 개별 추출 GSheet는 폴더 전체 탭을 내려받은 뒤 이름으로 필터하므로, 개별 선택이어도 네트워크 다운로드는 전체이고 저장되는 .bin만 선택분으로 줄어든다.

09페이지 — 코드 추출

목적: .bin → C#/C++ 클래스 생성. 전체 또는 선택 항목만. (구조는 바이너리 추출 페이지와 동일 패턴)

│  [☑ 모두]                                                            │
│  ┌ 바이너리 목록 (.bin) ──────┐   ┌──────────────────────┐          │
│  │ ☑ Item                     │   │  [ 전체 생성 ]         │          │
│  │ ☐ Character                │   ├──────────────────────┤          │
│  │ ☑ Stage                    │   │  [ 선택 생성 ]         │          │
│  └────────────────────────────┘   └──────────────────────┘          │
│  결과: Item.cs, Stage.cs 생성 (2)                                    │
└─────────────────────────────────────────────────────────────────────┘
요소동작 / 매핑
출력 언어C# 또는 C++ (Config의 확장자 규약과 연동)
Enum 코드 함께체크 시 EnumDB → enum .cs도 생성(전체 단위)
전체 생성Binary 폴더 전부 → tabletool generate
선택 생성체크 항목만 → generate -each <이름>

10공통 UX 패턴

패턴규칙
선택 목록체크박스 목록 + [모두] 토글 + [전체]/[선택] 실행 버튼. 바이너리·코드 페이지 동일
진행 표시실행 중 진행 바 + 현재 항목명. 취소 버튼(가능한 경우)
결과/로그하단 상태 바 요약 + 펼침 로그 패널. 성공 녹색 / 실패 적색
모달 최소화정보 전달은 페이지/패널로. 모달은 삭제·덮어쓰기 확인 등 파괴적 동작에만
미저장 보호편집 페이지 이탈/창 닫기 시 미저장 변경 있으면 확인
단축키Ctrl+S 저장 · Ctrl+F 검색 · F5 새로고침 (Editor 제약 내)

11데이터 흐름

  [원본]                    [중간]              [산출물]
  xlsx ─┐
        ├─▶ (바이너리 추출) ─▶  *.bin  ─▶ (코드 추출) ─▶  *.cs / *.h·cpp
  GSheet┘         ▲                            ▲
                  │                            │
             [Config 세팅] ── 경로·옵션 ───────┘
                  ▲
             EnumDB.bin  ◀── (Enum 생성, 전체 단위)

  뷰어 / 편집  ── 원본 또는 .bin 을 읽어 표시 · 수정

편집→저장→추출→코드생성이 한 창 안에서 연결되며, 모든 경로·옵션의 출처는 Config 페이지 한 곳이다.

12범위 밖 & 향후

  • 향후 Table Loader — UI/UX 미정으로 이번 제외. 확정되면 Config 세팅을 이 안으로 이동.
  • 향후 런타임 뷰어 — 데이터를 실제 게임에서 보여주는 부분은 엔진별 개별 구현(Unity/Unreal 등). 본 툴(에디터) 범위 밖.
  • 향후 다중 정렬 · 변경 이력/undo 스택 · 대량 편집(찾아 바꾸기).

13확인 필요 사항
